How to replace on mobile (30 seconds):
  1. Tap 📋 Copy Entire Code.gs below — it copies automatically.
  2. Open script.google.com in Chrome. Tap ⋮ → Desktop site (required — mobile editor is read-only otherwise).
  3. Open your SpaxButchery project → click Code.gs on the left → Select All → Paste → 💾 Save (Ctrl+S).
  4. If you changed keys, set GEMINI_API_KEY / MOONSHOT_API_KEY at the top, then Deploy → Manage deployments → ✏️ Edit → Deploy (or New deployment).

Why this page exists

Google’s Apps Script editor (script.google.com) is not editable on mobile — the code area is read-only unless you request Desktop site, and even then selecting/pasting is awkward. This page gives you a single large Copy button so you don’t have to pinch-zoom or drag-select. The file is also kept in the repo as google-apps-script.gs so any future update can be re-copied the same way.
